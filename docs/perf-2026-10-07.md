# Perf pass — 2026-10-07 (cheap tablet / iPad)

Target: shrink **menu** first paint on low-end tablets without changing game
rules or scoring. Scope was build config, routing/loader, and asset pipeline
only.

## What changed

1. **Lazy game route mounts** — help HTML + per-game shell wiring moved from
   `main.ts` into `src/ui/game-route-mounts.ts`, loaded only on `/game/:id`.
2. **Split play CSS** — board / tutorial / per-game chrome extracted to
   `src/ui/styles/game-play.css` and dynamic-imported with the game route
   (not linked on the menu HTML).
3. **Chunk policy** — `vite.shell-chunks.ts` keeps `game-routes` out of the
   menu `ui` / modulepreload graph; play CSS is left unnamed so Vite emits an
   async stylesheet.
4. **Asset trim** — drop unused `king.svg` from PWA `includeAssets`; exclude
   Inter 500/600/700 from Workbox precache and runtime-cache them on first use
   (400 stays precached + preloaded).
5. **Prefetch** — skip game-chunk prefetch when `navigator.connection.saveData`
   is set (matches idle-warm).
