# axe-core game screen audit — 2026-10-07 (part 2)

Scope: **2D** menu + all 20 available practice games after human Start.  
Builds on keyboard/SR work in PR #448.  
Harness: Playwright Chromium + `@axe-core/playwright` (`tests/e2e/a11y-axe.spec.ts`).  
Constraints: **no rules or scoring changes**.

## Mode

Default is **report-only**: each game writes `test-results/a11y-axe/<id>.json` and logs violations; the suite stays green.

Optional enforce (serious/critical on name/label/focus rules):

```bash
A11Y_AXE_ENFORCE=1 npx playwright test --project=chromium tests/e2e/a11y-axe.spec.ts
```

## Fixes landed this pass

| Issue | Severity | Fix |
| --- | --- | --- |
| Shell New Game / Tutorial / Help white-on-fill contrast | Serious | Stronger button fills (`--color-primary-strong`, system-dark, success-strong) |
| Status / seat text on light surfaces | Serious | `--color-player1-text` / `--color-player2-text` wired through game inject styles |
| Kwatro chip-info text on `#333` | Serious | `--color-player*-on-dark` |
| Menu inactive tab grades (opacity washout) | Serious | Solid `--color-neutral-600` (+ active tab light text) |
| Menu / Fab heading skip (h1 → h3) | Moderate | Game cards + Fab section headers use `h2` |
| ARIA `grid` without `row` parents (15 games) | Critical | `ensureAriaGridRows()` in `board-a11y.ts` (+ `.aria-grid-row { display: contents }`) |
| Entrance `fadeIn` false-positive contrast | — | E2E waits for `.game-selector` opacity settle before axe |

## How to re-run

```bash
npm run lint
npx tsc --noEmit
npm run test:unit
npx playwright test --project=chromium tests/e2e/a11y-axe.spec.ts
```

Reports: `test-results/a11y-axe/*.json` (gitignored via Playwright output).
