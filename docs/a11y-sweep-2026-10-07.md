# Accessibility sweep — 2026-10-07

Automated axe-core pass over shared shell surfaces (menu, settings-adjacent progress, help/rules, each game’s New Game start modal). Serious/critical findings only; no rules or scoring changes; no edits under `src/games/*`.

## Dependency

- Added `@axe-core/playwright` (devDependency) — allowed for this sweep; not previously present.
- Suite: `tests/e2e/a11y-sweep.spec.ts`
- Run: `npm run test:e2e -- --project=chromium tests/e2e/a11y-sweep.spec.ts`

## Screens covered

| Surface | Route / action | Notes |
| --- | --- | --- |
| Menu | `/` | Game selector hero, division tabs/accordions, game cards |
| Settings | `/#/stats` | **No dedicated Settings route** exists today. User settings live in storage (`owlEnabled`, `reducedMotion`) without a chrome screen. The progress dashboard is the shared secondary shell used as the settings-adjacent surface for this sweep. |
| Help / rules | `#help-btn` → `#help-modal` | Shared `mountGameShell` dialog (probed via Hex) |
| Game start | `#new-game-btn` → `#new-game-modal` | Every `GAMES` entry with `available: true` |

Board interiors (`#board`, game areas, a11y grids, Ollie) are excluded from game-start assertions so per-game playtest agents can own board-level a11y.

## Serious / critical findings and fixes

All fixes are in shared shell/menu CSS or `src/ui/components/game-shell.ts` (plus stats dashboard styles).

| Finding | Impact | Fix |
| --- | --- | --- |
| Menu container `fadeIn` opacity animation | Transient `color-contrast` on cards, tabs, grades while opacity &lt; 1 | Removed opacity animation on `.game-selector` (landmark/text container must stay at full opacity) |
| Division tab grade labels used `opacity: 0.7` | Fragile / mid-animation contrast | Solid muted colors; active tab grade white on a darker active gradient (`#1e3a8a` → `#1d4ed8`) |
| Progress empty-state CTA white on `--color-primary` (~3.7:1) | `color-contrast` | `.stats-dashboard-cta` uses `--color-primary-dark` (#2563eb, ≥4.5:1) |
| New Game / Help modals lacked dialog semantics | Landmark / SR naming | `role="dialog"`, `aria-modal="true"`, `aria-labelledby` on shared shell modals; focus moves into the dialog on open |

## Out of scope (documented, not fixed here)

- Per-game board cells, 3D a11y grids, quiz UIs under `src/games/*` / `src/ui/three/*`
- Moderate / minor axe rules
- Inventing a full Settings preferences UI (storage flags only today)
- Scoring, rules engines, or student-facing records
