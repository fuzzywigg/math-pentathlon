Run: `npm run test:e2e:mobile`  
Artifacts: `test-results/mobile/<project>/<gameId>.json` and `test-results/mobile/summary.md`  
CI: job `mobile-touch` is **report-only** (`continue-on-error: true`). Required e2e stays Chromium-only.

## Smoke flow (every available game)

1. Open `/#/game/<id>`, start human mode
2. Layout audit: horizontal overflow, chrome tap targets &lt;44px, off-screen chrome, missing `touch-action`, hover-only (`opacity: 0`) controls
3. A few legal moves via `tap()`
4. Open/close New Game + Help; toggle move-history badge when present (Kings)
5. Leave via Back → game list

Suite stays green unless `MOBILE_TOUCH_ENFORCE=1`.
