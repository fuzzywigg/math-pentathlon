# Tablet playability report — 2026-10-07

Honest kid-on-a-cheap-tablet pass of every menu game on `alpha` @ `593270b` (vs AI, no clocks).

## Method

| Item | Detail |
| --- | --- |
| App | `npm run dev` → `http://127.0.0.1:5173` |
| Browser | Playwright Chromium, headless |
| Viewport | 768×1024, `deviceScaleFactor: 2`, `hasTouch: true`, iPad Mini profile |
| Mode | New Game → Play vs AI → Easy / Medium / Hard (all three per game) |
| Stop conditions | Proper end/win/draw/tie screen, soft-lock (no legal action / no progress ~45s), max **90** human turns, or **~5 min** wall clock |
| Checks | End screen, soft-lock, AI think &gt; ~3s, input during AI thinking UI, unclear/broken copy, interactive targets &lt; 44px, console errors |
| Screenshots | One per game under [`docs/playtest/2026-10-07/`](./2026-10-07/) (tablet viewport) |

**Not in scope:** adding clocks, source fixes (report-only PR), production deploy.

**Limits:** Headless automation is not a real finger. Some “timeout” rows are long games that were still progressing (especially Hex). Soft-locks are called out only when the seat/UI stopped accepting a complete turn. AI-turn input was probed when `.status-ai-thinking` was visible; many games reply so fast that thinking chrome never appears.

**Related open drafts (#392–#412):** where titles clearly match a finding, the PR number is noted next to the issue.

## Cross-cutting observations

1. **Touch budget:** Shared chrome (`New Game` / `Tutorial` / `How to Play` / back) is commonly **~34–36px tall**. Ollie dismiss/minimize often **~23–24px wide**. Board cells/nodes frequently **&lt;44px** (Kings ~36px, Kwatro valid nodes ~17×19, Sum Dominoes hands ~40×20). Matches the intent of polish drafts [#392](https://github.com/fuzzywigg/math-pentathlon/pull/392), [#408](https://github.com/fuzzywigg/math-pentathlon/pull/408), [#410](https://github.com/fuzzywigg/math-pentathlon/pull/410), [#411](https://github.com/fuzzywigg/math-pentathlon/pull/411).
2. **AI input lock:** Where `.status-ai-thinking` appeared (Kings, Hex, Star Track, Hex-a-Gone, Calla, Queens), aggressive taps during think did **not** advance human selection. Many other games never show thinking chrome (instant reply); seat-lock regressions remain a risk — see [#401](https://github.com/fuzzywigg/math-pentathlon/pull/401), [#403](https://github.com/fuzzywigg/math-pentathlon/pull/403), [#405](https://github.com/fuzzywigg/math-pentathlon/pull/405), [#406](https://github.com/fuzzywigg/math-pentathlon/pull/406), [#407](https://github.com/fuzzywigg/math-pentathlon/pull/407), [#409](https://github.com/fuzzywigg/math-pentathlon/pull/409), [#412](https://github.com/fuzzywigg/math-pentathlon/pull/412).
3. **Clocks:** None observed; none added.

## Prioritized top-10 fixes

1. **Juggle — placement soft-lock** when a rolled shape will not fit (Easy/Hard). Critical for kids. → [#407](https://github.com/fuzzywigg/math-pentathlon/pull/407)
2. **Kwatro-Sinko — AI seat stall** on Red’s turn after long play (Easy). Critical. → [#397](https://github.com/fuzzywigg/math-pentathlon/pull/397) / [#393](https://github.com/fuzzywigg/math-pentathlon/pull/393)
3. **Shell + Ollie touch targets ≥44px** (global chrome). High. → [#392](https://github.com/fuzzywigg/math-pentathlon/pull/392), [#408](https://github.com/fuzzywigg/math-pentathlon/pull/408)
4. **Board hit targets ≥44px** (Hex cells, Kwatro nodes, Kings cells, FIAR nodes, Sum Dominoes hands). High. → [#411](https://github.com/fuzzywigg/math-pentathlon/pull/411), [#410](https://github.com/fuzzywigg/math-pentathlon/pull/410), [#398](https://github.com/fuzzywigg/math-pentathlon/pull/398)
5. **Pent'Em In — “Place the … piece” dead-end UX** without obvious legal cells / orientation. High. → [#403](https://github.com/fuzzywigg/math-pentathlon/pull/403)
6. **Prime Gold — mid-game “Roll the dice” stall** on Easy/Med after long sessions. High. → [#405](https://github.com/fuzzywigg/math-pentathlon/pull/405)
7. **Hex-a-Gone AI latency ~3.1s** every think on tablet. Medium–high. → [#397](https://github.com/fuzzywigg/math-pentathlon/pull/397), [#395](https://github.com/fuzzywigg/math-pentathlon/pull/395)
8. **Star Track winner string “You Wins!”** Medium (confusing for early readers). → [#412](https://github.com/fuzzywigg/math-pentathlon/pull/412)
9. **Fab-a-Diffy AI phase console failures** (`selectBar1` / `executeMove` in `confirmingMove`). Medium (game still ends, but brittle). → [#402](https://github.com/fuzzywigg/math-pentathlon/pull/402)
10. **FIAR move-phase clarity + touch** after placement (long, easy to mis-tap). Medium–high. → [#396](https://github.com/fuzzywigg/math-pentathlon/pull/396), [#410](https://github.com/fuzzywigg/math-pentathlon/pull/410)
